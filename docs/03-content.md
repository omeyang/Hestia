# 内容组织

## 两个入口

阶段索引回答“我现在该学什么、决定什么、检查什么”；主题索引回答“这个材料、工艺或要求的依据是什么”。阶段文章引用主题知识，避免复制后出现多个相互矛盾的版本。

## 从总览进入模块与子项

采用四层：**全周期总览 → 总模块 → 工种/工作阶段 → 子项任务卡**。详细目录以[装修模块与子项](13-stage-modules.md)为主记录，关联 `P-STAGE-09`；每项工作可以继续细分，目录不表示已核验或已完成。

| 总模块 | 包含的阶段 | 进入细项 |
| --- | --- | --- |
| A 筹备与方案 | 验房档案、需求设计、团队合同采购、开工交底 | [展开 A](13-stage-modules.md#module-a) |
| B 现场与隐蔽工程 | 拆改、门窗封窗（按需）、水电、系统前期配合 | [展开 B](13-stage-modules.md#module-b) |
| C 硬装工种 | 瓦工、木工、油工 | [展开 C](13-stage-modules.md#module-c) |
| D 定制、安装与收尾 | 定制安装、主材安装、设备末端、打胶收口修补 | [展开 D](13-stage-modules.md#module-d) |
| E 交付与入住 | 调试、竣工检查交接、保洁、家具软装、入住条件复核 | [展开 E](13-stage-modules.md#module-e) |
| F 使用、维护与迭代 | 维护、问题返修、复盘与再优化 | [展开 F](13-stage-modules.md#module-f) |

例如进入 B，再打开 B3 水电阶段，可分别阅读 B3.1 更换边界、B3.2 点位协调、B3.3 给水冷热水、B3.4 排水、B3.5 配电、B3.6 网络智能、B3.7 实施记录、B3.8 检查交接。子项使用[任务卡](../templates/module-task.md)记录资料、前置条件、交付、责任、状态与关系。

阶段树用于阅读；给排水、电气、暖通、定制等专业主题横向归集。实际先后与变更影响通过任务之间的具体依赖记录表达，不从目录编号推定。一个主题记录可以关联多个阶段，不复制成互相独立的版本。

[预留与交接](11-renovation-stages-and-reservations.md)保留已有 00—09 标签与 S00—S12 工作步骤的映射；每项设备继续记录决定、预留、安装、检查四个时点，另排采购与复尺。

采用[允许回改与关联更新](14-iteration-and-change-impact.md)：后续证据、需求、现场或可实施条件可以推动前面的整理与方案修订，保留历史并联动更新依赖它的子项、接口、采购和文章。关系当前人工维护，自动查询未实现。

## 主题分层

| 层次 | 内容 | 与其他层的关系 |
| --- | --- | --- |
| 要求与标准 | 原文定位、状态、术语、适用范围 | 给出依据及约束 |
| 材料与产品 | 性能、参数、检测与厂家说明 | 说明材料体系与选材条件 |
| 工艺与节点 | 基层、步骤、配套关系、失败条件 | 引用要求和材料条件 |
| 检查与验收 | 检查对象、方法、时点、合格依据 | 区分业主观察与专业检测 |
| 案例与排除 | 失败经验、争议、过时和不适用建议 | 解释经验边界与不采纳理由 |

主题可以按给排水、电气、防水、铺贴、门窗、供暖、空调、通风、照明、柜体和室内环境等扩展。

## 学习文章与阶段指南

`articles/` 保存主题学习文章，`guides/` 保存可执行阶段指南。学习文章围绕问题讲清认识、解释、过程、关键画面、条件及争议；可包含明确标注的待核验经验。指南结合本家条件组织行动，关键建议须有已核验且适用的依据。

主题学习文章使用[学习文章模板](../templates/learning-article.md)。一条视频通常成一篇，多主题可拆、同问题可合、重复或无有效信息可跳过。设一个主要阶段和关联阶段，跨阶段引用同一篇；安装类内容在早期需要决策时给出关联提醒。

视频表达与画面处理见[视频学习设计](08-video-learning-design.md)。转写保留在分析材料中，不作为文章正文交付；优化组织和表达时，不改变主张、补造参数或抹平真实争议。

## 阶段指南的固定结构

1. **结论**：本阶段要做的事，控制在可以快速读完的范围。
2. **适用条件**：房屋、地区、材料和前提；条件未知时说明缺口。
3. **决策与行动**：选择、比较、沟通问题和下一步。
4. **检查清单**：观察什么、何时检查、交给谁确认、依据是什么。
5. **常见误区**：被排除建议及简短原因。
6. **依据与限制**：结论 ID、来源定位、条文、核验日期与争议。

正文避免广告话术和没有条件的“必须”“最好”“永远”。必要术语就地解释，长解释与完整证据链接到主题记录。

## 实际决策记录

每项已确定方案保留：问题、候选方案、证据、预算影响、选定理由、未解决事项与确认日期。个人偏好与技术结论分别记录，不把本家的选择写成所有家庭的通用做法。

事实分歧使用[争议模板](../templates/dispute.md)，本家方案取舍使用[决策模板](../templates/decision.md)。记录明确关联的房屋档案版本、结论和文章 ID，并保留选择代价、所需专业或现场确认、复核触发条件及变更历史。尚未决定时保留待决策，不为了完成文章替业主作选择。

## 首篇文章

建议题目：**《西安 156㎡毛坯房：开工前先确认这些条件》**。

内容重点是交付情况、图纸、设备接口、物业要求、家庭需求、预算口径和最早需要锁定的决定。户型图与指定来源尚未提供，当前不填充具体设计或施工参数。

本家的家庭、必需家电及装修需求见[房屋需求基线](07-house-baseline.md)。首篇文章应覆盖整体水电更换、墙面/防水铲除，以及供暖、空调、新风、净水、网络与智能家居的前置问题。还需覆盖儿童长期使用、长辈阶段性居住、必需家电与清洁设备自动上下水、燃气热水器及零冷水取舍。供暖重铺、中央净水、软水、FTTR 和大循环零冷水保持待决策。
