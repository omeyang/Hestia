## 清理原则与本轮结果

本地 Doubao 根目录保留原始 JSON、两份分类 XLSX、更新后的项目说明；旧脚本、配套驱动和旧说明移入 `archive/20261024-legacy/`。归档清单记录原路径、现路径、文件大小及 SHA-256，并逐文件核对迁移前后哈希。恢复时根据清单移回相应位置；如目标已有同名文件，应先比对，不能覆盖。

只有替代工具验证完成且旧数据的追溯需求已结束，才考虑永久删除归档。本轮采用可恢复的移动整理，不删除原始 JSON、成果表或历史依据。

后续每轮使用“不可变原始快照 → 差异核查 → 有依据的清洗/分类记录 → 当前成果表”，所有变更按视频 URL 对齐。临时页面、驱动压缩包、失败尝试和重复导出在确认无唯一证据后再清理。批次目录保留一份原始快照、一份当前成果和一份变更记录，避免继续堆叠 `final_v2/v3`。
