# 0003：分层阅读与允许回改

- 日期：2026-10-13。
- 状态：采用文档组织与工作约定；自动依赖查询和影响传播未实现。
- 依据：用户要求阶段更细、采用总分和模块方式，并明确允许后续更可靠、更合适的信息或落地条件优化前面的内容，联动修改关联事项。

## 采用的方式

按全周期总览 → 六个总模块 → 工种/工作阶段 → 子项任务卡组织资料。阶段树负责阅读，专业主题负责横向归集，实际先后与影响通过具体对象的依赖关系记录。既有分类与工作编号保留映射，子项可以继续拆分。

材料、工艺、阶段、分析、结论与方案均允许迭代。记录技术判断变化与本家取舍变化，核对新旧证据和条件，保留历史，并更新直接及间接受影响的预留、图纸、预算采购、任务检查和文章。

已确认内容可以重看；已采购、加工或施工的项目需记录实际可实施方案、相关确认、费用工期与复验影响。变更完成后指定新当前基线，未完成的关联事项继续保持待办。

详细目录见[模块与子项](../13-stage-modules.md)，规则见[迭代与关联更新](../14-iteration-and-change-impact.md)。采用目录和修订方式不代表任何本家工程方案已核验，不改变来源白名单、房屋事实与隐私边界。
