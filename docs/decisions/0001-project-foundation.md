# 0001：项目初始化

- 日期：2026-10-13
- 状态：初始实施

## 名称

检查 GitHub 账号 `omeyang` 的远程仓库后，发现多数项目采用首字母大写的单个专名，其中 Maat、Thoth、Ptah、Pomona、Cloacina 使用与项目用途有关的神话名称。

选择 Hestia，与家庭和炉火的含义相呼应。中文定位为“有依据的装修学习与决策”。名称参考见 README。

## 远程仓库

用户明确授权创建项目并推送远程，并要求公开管理规则、文章模板等内容。建立公开仓库 `omeyang/Hestia`。

户型图等隐私资源未来通过云盘或 OSS 链接接入，不提交公开仓库。当前优先解决有效信息取得和核验，暂不开发存储插件。本次不推定第三方内容的再分发权限，不设置开源许可证。

## 初始交付

先建立方案、数据结构与模板，形成可审阅的项目基础。未收到指定经验链接和户型图，不生成带具体参数的施工文章。

当前房屋档案来自用户：西安、190㎡建筑面积、156㎡套内面积、完全毛坯。其他条件留空。

## 技术选择

初始使用 Markdown 和 JSON，直接在 GitHub 阅读和版本管理。暂不引入数据库、采集框架、AI 服务依赖或文档站。

自动化工作由真实小样本闭环决定。视频和图文获取方式保留适配空间，不能预设所有平台均可自动读取。

## 依据与局限

本次官方来源调研用于建立核验入口与识别明显失效文件，未完成标准全文阅读、条文适用判断和现场核查。参考入口不等于已核验结论。
