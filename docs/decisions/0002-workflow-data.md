# 0002：飞书多维表格与 PostgreSQL 分工

- 日期：2026-10-13。
- 状态：当前设计方向；未接入，部署和供应商待定。
- 依据：用户提出需要飞书表格与 PostgreSQL 两者协作。

## 方向

PostgreSQL 保存五阶段管道的任务、运行、来源版本、证据关系、结论与核验历史。飞书多维表格展示来源候选、处理进度、待核验事项和文章入口，并收集用户指定、审核意见和方案选择。

系统状态由 PostgreSQL 同步到飞书；用户操作以有身份、时间、版本和唯一 ID 的记录回流，经检查后执行。实现重复操作去重、同步重试、版本冲突处理与对账，不维护两套可互相覆盖的处理主记录。

来源指定仍以 `sources/registry.json` 的实际记录为准，房屋条件以现有档案为准。原始大文件和敏感资料保留在被忽略的 `local/`；文章正文保存在 Markdown，JSON 保留导出与离线处理能力。

## 接入与复核

按最小 PostgreSQL 记录、飞书展示、用户操作回流的顺序验证，不先扩建完整平台。具体职责、同步和验收见[协作方案](../10-online-workflow-data.md)。

根据真实小样本复核字段、工作量、网络、额度与恢复能力；托管供应商、实例区域和飞书应用权限在接入时确定。当前不代表已有数据库、表格或同步工具。
