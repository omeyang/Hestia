# 证据管理

本目录记录证据索引和保存约定。当前尚无指定经验来源的原始证据。

每份证据至少记录来源 ID、获取日期、内容版本/哈希、原文位置、允许保存的内容范围和处理方式。

定位方式：视频时间戳与关键帧位置；图文段落与图片位置；PDF 页码和条款号；GitHub 提交哈希、路径和必要的行号。

证据摘录、AI 解释和核验判断分别保存。原始内容不因后续清洗被覆盖；被排除片段保留定位与原因。

原始媒体、完整截图、户型图、报价、标准文件等先存入被忽略的 `local/`。隐私资源未来通过云盘或 OSS 链接接入，资源管理适配器不在当前阶段开发。公开索引只放可公开的元数据，不提交可访问私人文件的签名链接、令牌或个人资料。

索引里的本地路径应说明文件没有随仓库同步，不能产生“下载链接可用”的假象。

尚未获取原文的参考链接不能作为已经读取、已经转写或已经核验的证据。
