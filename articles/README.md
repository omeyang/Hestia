# 主题学习文章

本目录用于从指定视频等来源整理出的主题学习文章，以[业主阅读阶段](../docs/03-content.md)作为入口；既有 00—09 分类标签保留，按[阶段映射](../docs/11-renovation-stages-and-reservations.md#与已有分类和工作编号的映射)关联工种与工作步骤。当前仅有设计与模板，没有实际来源文章。

文章使用[主题学习文章模板](../templates/learning-article.md)，讲清问题、解释、过程、关键画面、条件和争议。转写是中间材料；待核验经验可以明确标注后用于学习，不冒充可执行指南。

每篇设一个主要阶段、关联阶段和主题标签；其他阶段引用同一篇，避免复制。多主题视频可以拆篇，同问题视频可以合篇，重复或无有效信息的视频可以记录跳过。

来源分析使用[视频分析模板](../templates/video-analysis.md)。独立结论保存在 `knowledge/`，按问题维护争议，按实际选择维护决策；符合核验与适用条件的内容再用于 `guides/`。

具体处理、核验与工具选择见[视频学习设计](../docs/08-video-learning-design.md)。公开配图须有允许的再分发范围；不能公开的关键画面只提供原视频定位。
