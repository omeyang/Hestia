# 主题知识

当前保存[阶段规划结论](stage-planning-claims.json)，区分组织提案、待核验接口问题、用户需求记录和实际核对的官方公告内容。尚不含已核验且适用于本家的施工结论。

[模块目录派生索引](stage-module-index.json)用于引用模块、阶段与子项编码；主记录是[分层目录](../docs/13-stage-modules.md)。它是规划索引，不表示任务、工程或技术结论已完成。修订采用[关联更新规则](../docs/14-iteration-and-change-impact.md)，新模板的版本和依赖字段在真实记录需要时补充。

按[内容组织](../docs/03-content.md)逐步建立要求与标准、材料与产品、工艺与节点、检查与验收、案例与排除记录。

独立结论使用稳定 ID，从[结论模板](../templates/claim.json)开始登记。核验状态与本房屋适用性分别维护。

阶段指南引用这里的结论和主题说明。来源或房屋条件变化时，保留旧版并复核引用关系。

主题学习文章也引用结论，但可明确标注待核验经验。表达理解、技术核验和本家适用性分别判断；同一作者前后改变意见时关联原记录，不自动覆盖。

有真实资料后按主题建立争议与决策记录，分别使用[争议模板](../templates/dispute.md)和[实际决策模板](../templates/decision.md)。前者保存集中取证及未解决分歧，后者保存本家方案取舍及复核条件；业主选择不使结论自动成为已核验。
